RACE 'N SMASH 

This is a game project I originally made
as part of the Lemon 64 games coding
tutorial FUN AND GAMES WITH ASSEMBLY.
The game code was developed using native
C64 tools for making graphics, sprites,
music, etc. The code was originally
developed for use with Turbo Assembler,
but I decided to prepare a cross-
assembly source of exactly the same 
game, for those who want to try it
in C64Studio or Acme Cross assembler.

All C64 graphics and music files from
the project are also provided.

The source files are as follows:


- RACENSMASH.ASM
This is the main target source code
file to compile.

- PROTOYPE.ASM 
This is the full code for the game
prototype, featuring block sprites

- GAMECODE.ASM
This is the enhanced version of the
game prototype, featuring the main
game screen, better graphics, a
smooth scrolling screen and also
music.

- TITLECODE.ASM
This is the main title screen code
source code. It builds up the
title screen presentation that 
displays a logo, flashing text,
scrolling text message and also
plays the title music.


COMPILING:

Compiling with C64Studio is 
straightforward. Go to the assembly
source file RACENSMASH.ASM and then
press F5 to compile and run the 
project in VICE. 

Compiling with ACME 

Go to the command prompt and call

nameofpath/acme/acme.exe racensmash.asm
